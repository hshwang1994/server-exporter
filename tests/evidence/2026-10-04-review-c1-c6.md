### 9-3. §5 실행 SHA 와 읽어 온 helper — 직접/추정 구분

- Jenkins 자체 기록: 콘솔 `Obtained <path> from git https://github.com/hshwang1994/server-expoter` 가 lightweight Jenkinsfile 과 readTrusted **네 파일** 모두에 남는다(main #88 콘솔 2 · 35 · 86 · 93 · 96행) — **출처(SCM)** 의 직접 기록이지 revision 기록은 아니다.

- 따라서 "중복 처리 계약" 과 "정상 수신 응답 본문" 은 모두 **미확인**이며, X2 runtime 부터 `[Callback] [OK] HTTP 200 response=<앞 200자>` 를 콘솔에 남겨 정상 전달의 Portal 응답이 JSON 인지 HTML 예외 페이지인지 구분한다(§9-9 에 결과). exactly-once · outbox · queue 는 만들지 않았다. Portal 코드/로그 확인은 Portal 담당 몫으로 남긴다.
